STEP 02 · TRANSPORT

A 3-way handshake opens the channel.

SYN · SYN-ACK · ACK ~1 RTT

TCP doesn't trust the network. Before any HTTP byte is sent, client and server agree on sequence numbers and window sizes via a three-way handshake.

// client → server
SYN seq=0
 
// server → client
SYN-ACK seq=0 ack=1
 
// client → server
ACK ack=1

Now both sides have a reliable, ordered stream. If a packet drops, TCP retransmits. If it arrives out of order, TCP reorders it. HTTP never sees any of this.
