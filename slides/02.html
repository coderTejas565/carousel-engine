STEP 01 · RESOLUTION

Before a single byte moves, the hostname must become an IP.

When you call fetch('/profile'), the browser doesn't know where api.tejas.systems lives. It asks a DNS resolver — which walks a hierarchy until an authoritative server answers.

01
OS cache
Local resolver checks TTL cache. Hit → done in ~0ms.
02
Recursive resolver
ISP or 1.1.1.1 queries root → TLD → authoritative NS.
03
A / AAAA record
Returns an IPv4 or IPv6 address. Now the OS can open a socket.
