STEP 04 · NETWORK

Your packets don't take a single path.

CLIENT → HOP → HOP → HOP → SERVER IP FORWARDING

Once the destination IP is known, IP packets are forwarded hop by hop through networks and routers toward the destination.

$ traceroute api.tejas.systems

2   10.0.0.1         8.4 ms
3   72.14.204.1       11.7 ms
4   142.250.46.1      14.2 ms
...    more hops
13   34.117.59.81      42.9 ms
Hop by hop
Each router looks at the destination IP and forwards the packet to its next hop.
Routing tables
Routers use routing information to decide where packets should go next.
Many networks
Internet traffic can cross multiple autonomous systems before reaching the server.
MENTAL MODEL
You don't control the exact route. The network forwards each packet toward its destination.
